# TerraShield NER - Landslide Risk Monitoring System

## Project Overview
TerraShield NER is an AI-based landslide risk monitoring and decision-support system developed for the North Eastern Region (NER) of India. The project explores the use of machine learning and environmental data for landslide susceptibility assessment and risk monitoring.

## Research Objective
The main objective of this project is to develop a system that can support landslide risk assessment by analysing relevant environmental and geographical factors and presenting the results through an interactive dashboard.

## Key Features
- Landslide susceptibility and risk monitoring
- Interactive regional dashboard
- Location-based risk information
- Environmental and geographical indicators
- Machine learning model for susceptibility analysis
- Risk alerts and decision-support information
- North Eastern Region focused monitoring

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Machine Learning
- Data Analysis and Visualization

## Project Structure
- `SlopeGuard-NER/index.html` - Main dashboard
- `SlopeGuard-NER/style.css` - Dashboard styling
- `SlopeGuard-NER/script.js` - Dashboard functionality
- `SlopeGuard-NER/data/` - Project data
- `SlopeGuard-NER/ml/` - Machine learning files and model

## How to Run
1. Download or clone this repository.
2. Open the `SlopeGuard-NER` folder.
3. Open `index.html` in a web browser.
4. For best results, the project can also be opened using Live Server in Visual Studio Code.
